### Multi-GPU Inference & Tool Execution Architecture


### Empirical Engineering Findings
- **The Early-Edit Invariant:** Trace forensics showed that runs attempting edits within $\le 12$ tool calls resolved **52.1%** of tasks. Runs spending $> 14$ calls reading without modifying files degraded to a **4.7%** resolution rate due to context clutter.
- **Clock Quota Donation:** Fast-exit passes on unambiguous tasks donated runtime to complex, multi-file repos, protecting the run against container cutoffs with a 100+ minute safety margin.
