A full-stack web application that facilitates live player auctions with role-based dashboards for admins, teams, and viewers. Built with a Node.js/Express backend, MySQL database, and a React frontend, it uses Socket.IO to deliver real-time updates for bidding, player assignments, and auction status to all participants.
