LineaRecta is a client-side web application that solves a classic geometry problem: finding the shortest distance between a point and a straight line. Built with vanilla HTML, CSS, and JavaScript, it provides an interactive experience where users can input the parameters of a line and the coordinates of a point, and see the result both numerically and visually on an HTML canvas.
