A comprehensive e-learning website designed to serve multiple chess academies from a single, unified platform. It features distinct portals for different academies (Aspire Chess Academy, KCA), offering course listings, event management, pro memberships, and educational content. The backend is powered by Node.js with a SQL database to manage all data.
