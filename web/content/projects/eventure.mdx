A collaborative web application designed to manage and gamify events like treasure hunts. It features a real-time progress tracking system using QR code check-ins, with dedicated dashboards for administrators to manage the event and for participants to track their journey and view leaderboards. The platform is built on a serverless architecture using Firebase for the backend.
