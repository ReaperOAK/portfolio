A full-stack, real-time skill-swapping marketplace built on the MERN stack. The platform enables users to offer skills they possess and find others to learn from in a direct, peer-to-peer exchange. It includes real-time notifications for swap requests via Socket.IO, a user reputation system with reviews, and a dedicated admin dashboard for platform management.
